# Аудит Career Quest по ТЗ — 23 сентября 2026

## Вывод

Основные пользовательские сценарии реализованы и проверены. Рабочий AI-навигатор
запускается командой `python run.py --demo-ai` на порту 8001: это отдельная база
независимых демонстрационных примеров, реальный OpenAI и повторяемый сценарий
сброса. В браузере подтверждены выбор модели, завершение и сохранение прогресса.
Основной запуск на порту 8000 сохраняет исходный датасет и его ограничение
`CQ_ALLOW_CLOUD_DATA=false`. Проверка независимого демо не доказывает качество
облачной модели на профилях жюри.

Аудит выполнен после объединения PR №2 (`7409f23`) с дополнительными исправлениями,
описанными ниже. Старые отчёты [QA.md](QA.md) и [QA_PR2.md](QA_PR2.md) относятся
к предыдущим проверкам; этот документ содержит актуальную сводку.

без автономных действий от имени сотрудника.

## Исправлено

1. **PR №2 не был включён в main и конфликтовал с последними правками.** Конфликты
   разрешены с сохранением изменений и тестов обоих участников; PR объединён.
2. **Импорт мог обрывать запрос на нетекстовых полях.** Возвращается ошибка 400;
   состояние не меняется. Исправление и тесты из PR №2.
3. **JSON с UTF-8 BOM отклонялся.** Теперь импортируется; CSV проверяет обязательные
   и повторяющиеся заголовки, число столбцов и синтаксис. Исправления из PR №2.
4. **Достигнутая цель смешивалась с отсутствием подходящего шага.** HR получил
   отдельные статус, счётчик и фильтр; решение опирается на фактические разрывы.
5. **Округление могло показывать 100% при незакрытом разрыве.** До выполнения всех
   требований максимум 99%; добавлен тест с дробным уровнем навыка.
6. **Экран навыков показывал только требования цели.** Добавлены все навыки профиля
   с актуальными уровнями и пометкой, входят ли они в выбранную цель.
7. **Выбор файла не был надёжно воспроизведён в инструменте браузера.** Добавлен
   альтернативный текстовый ввод JSON/CSV с тем же API и лимитом объёма. Этот путь
   проверен от ввода до появления профиля в HR. Ошибка чтения файла теперь подсказывает
   повторный выбор или текстовый ввод; причина прежнего сбоя файлового диалога не установлена.
8. **Роль AI была плохо видна в интерфейсе.** Блок назван «AI-навигатор: следующий
   шаг» и объясняет назначение модели; фактический режим LLM/правил продолжает
   отображаться отдельно. Эта правка не включает внешнюю обработку данных.
9. **Для локальной проверки AI требовался отдельный проверочный скрипт.** Добавлен
   полноценный браузерный режим `--demo-ai`, изолированная SQLite, кнопка повторения
   сценария и переход к навигатору с первого экрана. Разрешение на облачную обработку
   собственных примеров не переносится на импортированные профили или историю.
   Потеря доверенного происхождения сохраняется после перезапуска. Изменение
   владельца импортированной записи учитывается для обоих профилей.
10. **Причина сбоя модели была слишком общей.** Отдельно объясняются отсутствие
    ключа, ошибки доступа, неизвестная модель, квота и отсутствие ответа. Ключи
    и тела ответов провайдера не попадают в интерфейс.
11. **Входы на двух локальных портах конфликтовали.** Имена сессионных cookie теперь
    включают порт, основной режим и AI-демо можно открывать одновременно.
12. **Windows иногда обрывал соединение при отклонении POST-запроса.** Сервер читает
    тело с ограничением размера и времени до ответа 403, проверяя Host/Origin до
    разбора JSON и выполнения действий. Проверены 60 запросов с недопустимыми
    Host/Origin: каждый вернул читаемую ошибку без обрыва соединения.

## Оставшиеся риски и действия до сдачи

**Облачный AI на исходном датасете.** Рабочая демонстрация на собственных примерах
доступна командой `python run.py --demo-ai`. Для облачной обработки исходного набора
по-прежнему требуется подтверждённое разрешение организаторов; альтернативой
служит локальная модель. Демо не отключает это ограничение и не отправляет исходные
записи в облако.

**Организационный риск — GitHub Actions.** Запуски блокировались billing владельца
BAITC-Hacks. Локальные тесты проходят; зелёный CI этим не подтверждён. Исправление
на стороне владельца организации. Заявка через «Сдать решение» ещё не подтверждена.

**Качество рекомендации.** LLM выбирает из максимум восьми кандидатов, подготовленных
кодом, а объяснения формируются из проверенных фактов. Достоверность объяснений
проверена; модель не генерирует собственный текст причин. Подтверждён один живой
контрпример с критическим навыком; оценка на скрытых профилях жюри остаётся неизвестной.

**Эксплуатационные ограничения.** Это локальное приложение для хакатона: нет SSO,
TLS, LMS-подтверждения прохождения, аудита HR, резервирования и production-развёртывания.
Пароли демонстрационные, локальные индивидуальные пароли хранятся в файле. Публичной
ссылки нет; по указанным требованиям она нужна только при наличии развёрнутой версии.

**Интерпретация времени.** «Сегодня» берётся из среза 2026-10-01. Кнопка завершения
моделирует прохождение активности; проверка реального посещения и переноса записей
из LMS не реализована. Самостоятельное подтверждение допустимо для заявленного
демонстрационного сценария, но не заменяет интеграцию в банке.
