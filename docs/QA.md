# Проверка интерфейса и импорта

Дата: 23 сентября 2026 года. Проверка выполнена на независимых демонстрационных
данных проекта, без датасета организаторов и реальных персональных данных.

## Автоматические проверки

- Python 3.14: `python -m unittest discover -v` — 25 тестов пройдены.
- JavaScript: `node --check static/app.js` — синтаксических ошибок нет.
- Пять новых тестов воспроизводили проблемы до исправлений и проходят после них:
  различение достигнутой цели в HR, обработка нетекстовых полей импорта,
  JSON с UTF-8 BOM, отсутствующие и повторяющиеся заголовки CSV.
- Существующие проверки покрывают права employee/HR, рост и сохранение навыков,
  запрет повторного завершения, подбор кандидатов и проверку ответа модели.

## Проверка через браузер

| Сценарий | Результат |
| --- | --- |
| Фильтр «Цель достигнута» | Показывает Ready Employee; этот профиль исключён из фильтра «Нет следующего шага» |
| Поиск и сброс фильтров | Счётчик обновляется; сброс возвращает полный список |
| Импорт без файла | Понятная ошибка, повторная попытка доступна |
| CSV без completion_pct | Сообщение указывает недостающий столбец; профиль не добавляется |
| Импорт нового профиля из JSON | Профиль появляется в HR; кнопка перехода и поиск по ID работают |
| Завершение активности импортированного профиля | Прогресс меняется с 50% до 70%, обновляются история и HR; значение сохраняется после перезагрузки страницы |
| Мобильный экран, ширина 390 px | Нет горизонтального переполнения страницы; выбранный пункт навигации виден |
| Консоль браузера в проверенных сценариях | Ошибок JavaScript не обнаружено |

## Границы проверки

Реальный запрос к LLM в этой проверке не выполнялся. Проверки ответов модели
используют заглушки; доступность провайдера, качество живой рекомендации и задержку
на оборудовании защиты нужно проверить отдельно через `scripts/check_ai.py`.
Проверка на демонстрационных данных не заменяет приёмку на профилях жюри.
