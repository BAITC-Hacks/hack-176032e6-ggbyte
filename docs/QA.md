# Проверка работоспособности — 23 сентября 2026

Проверка выполнена после объединения PR #1. Среда: Windows, Python 3.13.5,
локальный HTTP-сервер и браузер Codex. Проверки с изменением данных выполнялись
в отдельной копии на независимых примерах; прогресс основной базы не изменялся.

| Проверка | Результат |

Скорости относятся к одному локальному прогону и не гарантируют задержку на
другом компьютере или при нагрузке.

## Исправлено при проверке

- HR-обзор теперь включает мероприятия без единого участия, с нулевыми счётчиками.
- У сотрудника без следующего шага при прогрессе 100% отображается «Цель достигнута»
  вместо «Нужен план с HR». Оба изменения проверены в браузере.

## Границы проверки

- При автоматизированном выборе JSON-файла через браузер операция чтения файла
  вернула `A requested file or directory could not be found`. Файл существует
  на диске; импорт тех же данных через HTTP API прошёл. Причина сбоя выбора файла
  не установлена. Полный сценарий выбора локального файла в интерфейсе этим
  прогоном не подтверждён и требует ручной проверки перед защитой.
- Облачная обработка исходного датасета в основном запуске выключена настройкой
  `CQ_ALLOW_CLOUD_DATA=false`. Реальный запрос OpenAI выполнен только на независимом
  примере. Браузерные сценарии проверялись в режиме правил; полный сценарий
  «браузер → LLM → браузер» на исходном датасете этим прогоном не подтверждён.
- Живой инференс NVIDIA и Ollama не проверялся.
- GitHub Actions ранее не запускал тесты из-за billing-блокировки аккаунта.
  Указанный результат 21 теста — локальный, а не успешный статус CI.
